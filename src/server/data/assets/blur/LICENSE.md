# Blur Guess asset license

All images in this folder and in `public/blur/` are original vector drawings
generated by `scripts/build-blur-assets.mjs` for GroupLore. They are released
as CC0 / public domain to the extent permitted by law. No third-party image is
used.

The manifest records the license and source for every subject. The test suite
rejects an entry without a `license`, `source`, six stage images, or a sharp
image.
